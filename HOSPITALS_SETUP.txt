HOSPITALS: HOW TO ADD DATA (Firebase Console -> Firestore Database -> Data)

1) Start collection:  hospitals      (then "Add document", Document ID = Auto-ID)
2) Fields for each hospital:

   name       string    Example Hospital Name        (required)
   address    string    Road, Area, City
   phone      string    01XXXXXXXXX or 041XXXXXXX    (used by the Call button)
   lat        number    22.xxxxx                     (latitude  - type: number, NOT string)
   lng        number    89.xxxxx                     (longitude - type: number, NOT string)
   emergency  boolean   true                         (optional: 24h emergency)

3) How to get lat / lng from Google Maps:
   - Open Google Maps, search the hospital.
   - Right-click (PC) or long-press (phone) on the hospital pin.
   - The first line shows "22.xxxx, 89.xxxx": the first number is lat, the second is lng.

4) Get the phone number from the hospital's Google Maps page or official website,
   and CALL it once to confirm it works before you add it.

5) Firestore rules - add inside "match /databases/{database}/documents { ... }":

   match /hospitals/{hospitalId} {
     allow read: if request.auth != null;
     allow write: if false;      // only you (Firebase Console) can add or change hospitals
   }

ADD YOUR OWN HOSPITAL FROM GOOGLE MAPS (inside the app)
- Google Maps -> open the hospital -> Share -> ResQ  (or Hospitals tab -> "Add a hospital").
- The name, address and location are filled in; type the phone number and tap Save.
- Saved privately at users/{uid}/myHospitals, so NO extra rules are needed.
- If the link cannot be read, long-press the hospital pin in Maps and paste the coordinates.
